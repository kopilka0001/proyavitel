# БРИФ: игра-валидатор «Проявитель+» (v2, актуальная)

**Как пользоваться:** это самодостаточный документ. Скопируйте целиком в новый чат — ИИ-помощник получит весь контекст проекта без пересказа прошлых диалогов. Дата последней ревизии: 15.11.2026. Рабочая договорённость: ИИ отвечает с фактчекингом, без «розовых очков» и галлюцинаций; непроверяемое помечается честно.

## 1. Контекст проекта

**Что это:** HTML5-игра-валидатор. Изначальная гипотеза — «люди готовы смеяться вслух в микрофон ради игрового результата». После проработки эмоционального сценария гипотеза расширена: «люди готовы смеяться/дышать в микрофон, если это снимает напряжение реального дня».

**Статус проекта:** игра — предпродажный тест механики для большой казуальной игры «Хохоток» (питомец-тамагочи, которого кормят смехом; целевая витрина — Яндекс Игры). «Проявитель+» — третий из трёх валидаторов: «Расцвет» (точность дозирования смеха) → «Тьма» (выносливость непрерывного смеха) → «Проявитель+».

**Разработчик:** соло, с использованием ИИ. Бюджет: нулевой на старте (потом — до ~5 200 ₽/мес из личной подушки). Язык интерфейса: русский (первая версия).

**Важно про историю идей (все зафиксированы, отсюда же выросла текущая механика):**
- Исходная: фото комнаты → серый кадр → смех проявляет цвет → пересмеял = кислота → белый финал «вознесение».
- Стресс-сдвиг: негатив — топливо игры, а не украшение. Но «фотографируй начальника» — юридическая и модерационная мина (ст. 152.1 ГК РФ, травля) → смеяться над **ситуацией**, а не над **человеком**.
- «Баблы на любимом кадре» (идея от 14.11.2026): любимая картинка накрывается серыми пузырями-раздражителями → лопаешь смехом → под ними цвет → свет. Оценка 9/10.
- **Финальная версия механики (актуальная) — скрибл-вариант**, см. п. 3. Она лучше подписной бабл-версии: черкание = скрибл-техника арт-терапии, баблы без надписей = чистая дефузия, лесенка «дуй→фыркни→хихикай» = титрование + встроенная дыхательная регуляция.

## 2. Концепция

Не «сессия на 2,5 минуты», а **тёмная комната фотографа**. Игрок — обладатель полароида, который проявляет не снимки, а своё состояние. Мир игры чёрно-белый и расцветает от действий самого игрока. Свободная фраза-питч: «закутай то, что давит, в противные пузыри — и сдуй их смехом».

## 3. Контур сессии — неприкосновенное ядро (нарушать нельзя)

1. **Тяготы дня.** Игрок вспоминает, что его тяготит (30–40 сек максимум — руминация ограничена таймером), хаотично черкает пальцем по экрану — по траектории образуются **серые пузыри без надписей**. Путь «один тап»: основной вход — выбор из готовых тегов; свободный текст и загрузка своей картинки — опциональные «ручки» (в Яндекс-сборке загрузку картинок не тянуть — модерационный риск UGC).
2. **Дуновение (выдох в микрофон).** Пузыри раздуваются, шевелятся и уплывают вверх, как отпущенные воздушные шары (не лопаются — «проблема перестала быть моей», а не «убита»).
3. **Лесенка хихиканья (титрование).** «Фыркни» → «хихикни» → «сильнее» → смех. Разозлённый игрок не может сразу рассмеяться — игра ведёт по лесенке, а не требует веселья. Подсказки нарастают: сначала дуновение качает пузыри, потом один маленький бабл становится полупрозрачным-радужным и лопается.
4. **Проявка.** Цвет не включается мгновенно, а расползается пятнами из точек разрыва (точная метафора того, как позитив вытесняет негатив). Кадр: серость → цвет → яркость.
5. **Спуск.** Подуть ещё — каждое дуновение функционально смягчает экран к тёплому кремовому (микрофон слышит выдох лучше смеха; метрика `descent_breaths`). ~30 сек. Гул-метроном, облака, покой.
6. **Вопрос «стало легче?»** — только после спуска, никогда на пике. Форма: выбор из четырёх слов-состояний **«теплее / спокойнее / легче / по-прежнему»** — без «неправильного» ответа. Ветка «по-прежнему» спроектирована тепло: «Сегодня так. Кадр всё равно остался с тобой». Рандомизировать формулировки между сессиями для чистоты данных.
7. **Полка.** Кадр вешается на полку, полка светлеет. Якорь возврата.
8. **Титры** (редкие показы): благодарность поддержавшим в формате соучастия, не клуба: «Спасибо тем, кто помогает свету: имена… ♥» + тихая кнопка «♥ Поддержать». Никаких «вы тоже можете стать одним из них» — это делит игроков и портит финал.

**Правило пика и конца** (применять ко всем финалам): сессия запоминается по пиковому моменту и по концу — финальная фаза (саворинг 10–15 сек без единого UI → спуск → прощание → полка → опционально шаринг) — не декорация, а конструкция памяти. Шаринг — только стилизованный кадр в брендовой рамке, никогда не исходное фото и не список раздражителей; формулировка без долга: «Отправить кому-то, у кого тоже был день». Финальная фаза — **модульная система**: саворинг → спуск с дыханием → облака-покой → вопрос-отражение → полка → шаринг; разные сессии собирают разные комбинации, аналитика сравнивает их по «легче» и возврату на следующий день.

## 4. Топ-5 радостных образов

Первые пять сессий выдают образы случайно из пятёрки ассоциаций с радостью/освобождением (отбор — из валидаторной практики: свет, облака, вода, простор, полёт). Аналитика покажет, какой образ даёт лучший выход в «легче» — валидатор становится лабораторией выбора героя мира «Хохотка».

## 5. Научное обоснование (можно цитировать в описании игры)

| Элемент механики | Метод | Статус доказательств |
|---|---|---|
| Смеяться над ситуацией, которая злила | Юмористическая переоценка | Сильное; сильнее «серьёзной» переоценки (с нюансом: часть исследований — «одинаково эффективны») |
| Серые пузыри как отдельные от «я» объекты | Когнитивная дефузия (ACT) | Хорошие данные; механика совпадает буквально |
| Тягота → безымянный бабл | Экстернализация (нарративная терапия Уайта) | Устоявшаяся практика; РКИ ограничены |
| Весь контур: экстернализация → трансформация → реинтеграция | Арт-терапия (модель Джонсона), скрибл-техника | Клиническая модель |
| Смех как таковой | Laughter-терапия | Кортизол −32% (мета-анализ PLoS One 2023), тревога SMD = −0,83; **но** эффект варьирует, гетерогенность высокая (I²≈74%) — клясться «минус треть стресса у каждого» нельзя |
| Длинный выдох (дуновение) | Парасимпатическое торможение | Мета-анализ 154 исследований: гасит возбуждение надёжнее «выпускания пара» |

**Главный миф, от которого спастись: катарсис.** Бушман (2002): «выпускание пара» — как тушить пожар бензином; даже «ничего не делать» лучше вымещения. Поэтому смех в игре — генератор позитивных эмоций и переоценка, а НЕ слив гнева.

**Три правила безопасности (вшить в дизайн и тексты):**
1. **Смех, а не выкрик.** Никакого «орёв гнева в бабл» — калибровка через фырканье ведёт к лёгкому смеху.
2. **Дистанция, а не руминация.** Никаких «вспомни, как он тебя задел» — тексты работают на дистанцию (карикатура = дистанция). Руминация ограничена: 30–40 сек, дальше — в объект, не в голову.
3. **Добрый юмор, не тёмный.** «Злой» юмор связан с худшей регуляцией эмоций (PLOS One 2019).

**Честные границы:** экспрессивное письмо Пеннебейкера — эффект мал/неоднороден (поэтому теги вместо «письма о пережитом»); механика синергична терапии, но это **не терапия** — в описании игры только «помогает расслабиться», не «лечит тревогу»; не продавать «убежище от проблем» (escapism в исследованиях связан с худшими исходами), продавать «пятиминутный инструмент для дня».

| Траекторный | «Меняется ли вечернее состояние от регулярного использования?» | Онбординг и 14-й день | **STAI-8** (рекомендуется вместо STAI-6: свежая русская адаптация 2023, альфа > 0,7; STAI-6 тоже защитима по данным 2020, но есть противоречие в литературе) |

- Одиночный вопрос 0–10 валиден (Frontiers, команда Titov/Fisher; VAMS r = 0,79) — не перегружаем ритуал длинными шкалами.
- Правила неубиваемости: опросы только до входа и после титров; всегда кнопка «Пропустить» (событие `survey_skipped`); STAI-8 — один раз за период.
- Честность в брифе: оба инструмента валидированы на клинических выборках; результаты валидатора — **сигнал, требующий проверки**, не доказательство эффекта. Малая выборка (30–50) — описательная, самоотбор и эффект ожидания учитываются.
- WHO-5 — отложено в опциональные (лицензия CC BY-NC-SA 3.0 IGO — проверить при коммерциализации; официальный русский перевод под вопросом).

## 7. Техническая архитектура

**База:** чистый HTML5 + Web Audio API + canvas. Ноль библиотек, ноль нейросетей, вес — десятки килобайт. Работает в iframe. Десктоп — мышь/стрелки (обязательный режим).

**Детектор — двухуровневый, с временными окнами** (не решаем «что делает человек вообще», решаем «что он сделал в окне, куда игра его позвала»):
- Уровень 1 (каждые ~50 мс, чистый DSP): энергия RMS → «дышит в микрофон»; гладкость огибающей → сила дуновения (гладкий медленный выдох = дуновение, резкий = порыв); модуляция 4–6 Гц → ритм смеха/фырканья.
- Уровень 2 (в конце окна): питч есть + ритм 4–6 Гц + длительность ≥ 0,4 с → смех; питча нет + серия импульсов → фырканье; питча нет + гладкая огибающая 0,5–2 с → выдох.
- Критично: **вдох микрофон не слышит** — все механики строить на выдохе, вдох = пауза перед выдохом.
- Честность: даже у профессиональных детекторов точность ~0,75 — дизайн обязан прощать 25% (щедрые пороги, фолбэк).
- Проверка «смех не смех» — пять ручных тестов до кода раундов: смех, шум телевизора, выдох, фырканье, обычная речь — с критериями «валидно/провал».
- События качества детектора: `event_detected`, `event_confidence`, `misfire_rate`.

**Карикатура (превращение фото в рисунок, почти бесплатно):** при импорте один раз считаем карту контуров (Sobel) → в реальном времени только дешёвые операции: насыщенность, постеризация (24 → 4 уровня), прозрачность слоя контуров. Считать в низком разрешении (320–480 px) и растягивать — для рисованного стиля это плюс. Слабые контуры приглушать порогом. Слой шкалы смеха трёхслойный: серость→цвет, фото→рисунок (контуры проявляются, уровней меньше — сцена становится «как в мире Хохотка»), рисунок→кислота→свет.

**Обработка кадра:** снимок в `<canvas>` дважды (серый + цветной слои); при скрибл-механике баблы рисуются поверх; надувание/лопание — стандартные канвас-операции. Простой режим — CSS-фильтры `saturate()/brightness()/grayscale()`.

**Наклон:** DeviceOrientationEvent; на iOS `requestPermission()` строго по тапу (лучше объединить с запросом микрофона); автоцентрирование нуля при старте. Десктоп — мышь/стрелки.

**iOS Safari:** graceful fallback на тап-режим в любой момент (отзыв разрешения, lockout).

**Хостинг валидатора:** GitHub Pages (HTTPS) + Telegram Mini App через BotFather (основной канал теста) + itch.io (ZIP ≤ 64 МБ, index.html в корне). RuStore-альфа — отдельно ценна: нативный микрофон без iframe — эталонная проверка детектора в реальном мобильном окружении.

## 9. Монетизация

**Принципы (неприкосновенные):**
- Смех не продаётся и не блокируется за деньги. Бесплатное ядро (тяготы → пузыри → дуновение → лесенка → проявка → спуск) — **бесплатно всегда и без квоты**. Пейволл посреди ритуала разрушает доверие.
- В валидаторе монетизации нет (fake-door на почту — да). Монетизируется «Хохоток», валидатор — эксперимент и сбор аудитории.
- Реклама только вне сессии: rewarded за добровольные бонусы (превью сцены, ретроспектива месяца) — не за кадры; interstitial между днями ухода, никогда после кремового покоя. В Telegram — без рекламы вообще (чистый полигон).
- Почта собирается после 2-й успешной сессии под конкретное обещание: «Кадр дня завтра будет другой. Хочешь, напомним?» Ожидание честное: 1–3% от вернувшихся. Fake-door в каталоге сцен: «Эта сцена скоро в „Хохотке“ — оставь почту». Нельзя запирать базовые функции за почту.
- Нет «условного шаринга» (если полегчало → расскажи друзьям): ответ «да» не должен ничего открывать — это портит и данные, и доверие.

**Стек Яндекса (уточнено фактчеком):** дележ 50% — только для инап-покупок; рекламная выручка — «по акту», цифры консоли ознакомительные. Минимальная выплата 3 000 ₽, раз в месяц. Подписок у разработчика на платформе нет, поэтому «подписка» реализуется инапами:
- Пачка кадров (99 ₽) — расходуемая инап (киты); восстановление покупок обязательно.
- «Сезон плёнки» (~1490 ₽/год) — непотребляемая инап: годовая «плёнка без дна» + сцены + рамки. Плёнка — не лимит, а нарративный ресурс («в этом месяце у тебя 12 кадров»), только на кадры сверх ежедневного ритуала. Текст пейволла продаёт избыток, не доступ.
- «Смотритель света» — инап-донат с местом в титрах.
- Бонусы Яндекса за игроков с Плюсом + программа дистрибуции — пассивные каналы, учитывать отдельно.

**Прогноз:** при 30k MAU гибрид ~48–109 тыс. ₽/мес после дележа; реклама при коротком ритуале — до ~21 тыс. даже при оптимистичном eCPM (реальные eCPM РСЯ просели: кейс «Новый Пасьянс» ~25 ₽). Ориентир новичка на Яндексе — не более ~20 000 ₽ с одной игры. Планировать только на рекламу нельзя: волатильна, уязвима к бот-атакам (задокументированный кейс обнуления дохода).

**Ретроспективный опыт рынка дыхательных/терапевтических приложений** (цифры — оценки аналитиков Adapty/Sensor Tower, расходятся в 2–3 раза; использовать для порядка величин): Finch, Calm, Breathwrk, Othership — люди платят за ритуал и избыток, а не за «доступ к лечению». Прецеденты механики микрофон-сенсора: DEEP (VR), Life Tree (2–3-минутные сессии — норма), Bubble Breather (микрофон достаточен), BreathQuest. Ниша «микрофон как контроллер эмоций» свободна (возможно, потому что спрос узкий — учесть).

## 10. Удержание и рейтинги

**Четыре крючка возврата:** «кадр дня» (одинаковая сцена у всех, рейтинг за сутки, обнуление — главный движок и то, что закрывает правило 2.9); коллекция штампов (за чистые проявки; белый финал и чистое проявление дают разные коллекции); мягкий стрик («дней без перерыва», пропуск просто сбрасывает — без вины и без «восстанови за рекламу»); физиология (смех — разрядка, финал должен оставлять «мне стало легче»).

**Лидерборды** (SDK Яндекса, счёт — целое число, направление задаётся в консоли; для «быстрее» — инвертированный счёт `score = 1 000 000 − мс`): «Мастер проявки» (точность×500 + волны×10 + бонус за чистое завершение), «Блиц-проявка» (время до чистого попадания), «Стойкость на грани» (секунды удержания кислотной фазы), «Кадр дня». Дублировать рекорды в localStorage (лидерборд только для авторизованных).

**Прогрессия:** уровни просветления (разблокировка сцен за пороги), вызов друга (асинхронно, без бэкенда), призраки-эталоны, командный зачёт. **«Хор»** (3–5 игроков смеются в общий кадр, суммарная насыщенность в окне цели) — козырная синхронная механика, решает стеснение микрофона; требует бэкенда — оставить как флагманскую фичу «Хохотка».

## 12. Гипотезы и зелёные пороги

1. ≥ 50% дошедших до геймплея реально смеются вслух (детекция по калиброванному максимуму).
2. ≥ 2 смен громкости у медианы внутри раунда — громкость как инструмент, а не «кричи громче».
3. ≥ 40% намеренно пересмеивают ради красивого финала — «фейл» как желанный контент.
4. Конверсия в разрешение камеры ≥ 40% (камера — барьер тяжелее микрофона; это данные, не провал).
5. После сессии легче (сессионный 0–10 до/после; форма вопроса — без «правильного» ответа, рандомизация формулировок).
6. Своя картинка (с чем себя ассоциируешь) даёт больший подъём настроения, чем заготовленная сцена (сравнение путей).
7. Траекторная: через 2 недели регулярного использования вечернее состояние улучшается (STAI-8).

## 14. Бренд и тон

Палитра: кремовый/дымчатый + янтарный/лавандовый/зелёный акценты. Персонаж-компаньон «хохоток» — пушистое круглое существо с двумя антенками-динамиками, глаза-полумесяцы; на краю экрана, реагирует комично (фейл = зажмуривается, закрывает лицо лапкой). Тон: тёплый, без хоррора, без насилия над персонажем. Графика — 2D-иллюстрация, толстый дымчатый контур, пастель. Карикатурный пайплайн выводит кадры в этот же стиль — скриншоты валидатора = арт-мостик к «Хохотку».

## 15. Ограничения и принципы

- Аудио не сохраняется и не отправляется; кадр живёт только в сессии; хранятся только числа.
- Не более одного уведомления игроку за сессию; любой провал комичен, без наказаний.
- Дублёр (тап-режим) доступен с первого экрана; тестировщику разрешено играть без звука — его выбор ценнее принуждения.
- Приватность: никаких автопубликаций фото в ленты и вызовы; в аналитику — только коды тегов, не тексты и не изображения.
- Формулировки в описании: «помогает расслабиться», никогда «лечит тревогу».
- Один запрос микрофона — до него собственный объясняющий экран: «Сейчас браузер спросит про микрофон — он нужен, чтобы задувать баблы. Можно играть и без него» + кнопки «Разрешить» / «Без микрофона» (отказ неунизителен).

## 16. Аудитория тестирования

**Два вида тестеров (не путать):** целевые — 30–40 человек с потребностью самопомощи (НЕ геймеры — иначе ложный отказ «слишком простая игра»); технические — 5–10 геймдев/QA (терпимы к сырости, ловят баги детектора).

**Сегменты целевых:** «Волновые» ~40% (25–40 лет, эпизоды стресса: офис, фриланс, молодые родители) — проверка кластерных сессий; «Воскресные» ~35% (уже в самопомощи: психологические каналы, майндфулнесс) — качественный фидбек по тону; студенты в сезон сессии ~15–20% (подключать в декабре–январе); диаспора — опционально. Знакомых — максимум треть, остальное — незнакомцы (иначе «вежливая ложь»).

**Каналы (волна 1 — 10–12 личных писем в золотые каналы, волна 2 — 20–30 + QA-чаты):** Reddit r/PlayMyGame (85 тыс.), r/DestroyMyGame (13,6 тыс.), r/playtesters; Telegram: Indie Spotlight (18,1 тыс., @indieSpotChat — двойное назначение: тех-тестеры сейчас, маркетинг после публикации), «Практика гейм-дизайна» @justChatGD (9,4 тыс.), QA-каналы (Серьёзный тестировщик 29,8 тыс., Тестировщик от бога 29,2 тыс., @qajuniors), психологические/самопомощь-каналы (размеры проверять в TGStat). Скрининг-анкета 4–5 вопросов (привычка самопомощи + частота игр) перед раздачей ссылок. Параллельно RuStore-альфа для тех, у кого не заработал микрофон в Telegram.

## 17. Черновик для модерации Яндекса (спека)

Не «тестовый экранчик», а зародыш игры (модерация завернёт стенд, правило 2.9 снимет коротыша). Три цели: микрофон в iframe (мобильный — главный вопрос), прохождение модерации, базовые метрики. Шесть экранов: 1) обложка (первый жест = разблокировка AudioContext), 2) объясняющий экран микрофона ДО системного промпта, 3) калибровка 30 сек (10 «подуй» + 10 «хихикни» + 10 тишина для фона), 4) сессия-ядро (полный контур), 5) полка, 6) кадр дня (первый за день — без плёнки). Чек-лист самопроверки перед отправкой: SDK без ошибок, пауза звука при рекламе/сворачивании, `LoadingAPI.ready()`, сохранение прогресса, мышь+тач, ru+en, ≤100 МБ, чистое описание. Кулдаун 16 дней — отправлять только собранное.

## 18. Открытые вопросы (продолжить отсюда)

- Спека скрибл-механики: количество/размеры баблов, логика лопания (какой бабл лопается от какого уровня: ближайший к точке внимания по наклону? случайный?), скорость расползания цвета из точек разрыва.
- Спека модульной финальной фазы: тайминги и дословные тексты каждого модуля.
- Тексты экранов опроса (STAI-8 из адаптации 2023, шкала 0–10, экран 14-го дня).
- Промт для ИИ-программиста под двухуровневый детектор (RMS/огибающая/4–6 Гц + окна классификации, fallback, iOS-ограничения, схема событий).
- Минимальный тестовый ZIP (один экран + getUserMedia + лог) для проверки микрофона в песочнице Яндекса.
- Таблица балансов (пороги, инерция, длительности) — после первого плейтеста.
- Титры как модуль финальной фазы: тайминги, A/B формулировок (соучастие vs клуб), частотный кап.
- Финансовая таблица с листом «личная подушка» (вставить реальную цифру среднемесячного расхода).

## 19. Словарь простых слов

MAU — сколько разных людей заходили за месяц. DAU — за день. Сальдо — сколько денег на руках после всех трат. D7 — доля людей, вернувшихся на 7-й день. Кит — игрок, который много платит. Fake-door — кнопка несуществующей фичи, меряющая спрос до разработки. eCPM — сколько платят за 1000 рекламных показов. Interstitial — принудительная межэкранная реклама. Rewarded — реклама по желанию игрока за бонус. Retention — возвращаемость. Conversion — доля шагнувших на следующий шаг.
